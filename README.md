# 快樂鳥一起點餐

依照 `ding2tong/timetoeat` 的多人接力點餐流程，改製成快樂鳥餐廳菜單。

## 使用方式

直接開啟 `index.html`，或在專案目錄執行：

```bash
python3 -m http.server 4173
```

再前往 <http://localhost:4173>。

## 功能

- 77 個菜單品項與分類
- 多位成員、多品項與數量
- 每道餐點備註
- 符合主餐搭配的氣泡飲料半價自動折抵
- 10% 服務費與總價預估
- 一鍵複製 LINE 訂單

菜單價格依 2026 年 7 月提供的八張照片建檔，實際供應與價格以餐廳現場為準。
